# Authoring coordination

本目录只保存多窗口 authoring 的轻量协调记录，不保存科研 Skill 内容或架构规则。

当前内容：

```text
coordination/
├── file_ownership.yaml
└── window_work_orders/
    └── README.md
```

- `file_ownership.yaml`：记录当前 writer assignments / write locks；
- `window_work_orders/README.md`：显式网页窗口任务单与待处理 cross-Skill follow-up 的导航入口；
- `window_work_orders/`：保存对应的具体 work order / follow-up 文件。

普通单窗口 Skill authoring 不需要读取本目录。多窗口情况下按 `00_authoring/SKILL.md` 和 `references/multi_window_authoring_protocol.md` 按需读取。
