# 2.4 OPT / FREQ

## 计算设置

开始计算前，确定代表实例参数化模型的总电荷和自旋多重度。

根据当前分子的元素组成、电子结构和后续参数化要求确定实际采用的量化计算方法、基组、溶剂模型及其它计算设置，并在对应量化计算任务中保留实际设置。

## OPT

对代表实例的完整参数化模型进行几何优化。

2.4 参数化模型不包含 topology-linked 参数化中的外围截断或 CAP，因此不继承 2.3 因模型边界而设置的固定原子规则。若当前实际参数化方法另有明确的坐标约束依据，由执行 Agent 根据该方法确定并记录实际设置。

## FREQ

在几何优化得到的结构上进行 FREQ 计算，获得后续 Sobtop 参数化所需的振动 / Hessian 信息。

在拟合成键项前，检查 FREQ 结果中的虚频及对应振动模式，确认当前结果能够用于代表实例的参数化。
